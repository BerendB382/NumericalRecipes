\subsection{1b. Fitting a chi-squared using Levenberg-Marquardt}
For this subquestion, we bin our radial data and use a Levenberg-Marquardt fitting routine to fit a chi-squared on the data. The relevant code is given below:
\lstinputlisting[language=Python, firstline=155, lastline=370]{Satellites2.py}

We bin our data in log space, so that the bins are of equal width when we plot them and the function in log space. We choose the range from $[10^{-4}, 5]$. We take 40 radial bins.

We bin our data using the bin$\_$data function, which normalizes the bins by the amount of halos as well as the bin widths. Importantly, this means that the function we fit will also have to be normalized to this.

In this section, we perform a G test on the fits obtained in the previous two subquestions. The code is given below:

\lstinputlisting[language=Python, firstline = 580, lastline = 639]{Satellites2.py}

The output is given here. As apparent, all the P values are exactly 1. Something went wrong in the G testing, most likely due to minimization.

\lstinputlisting[firstline=129, lastline = 148]{satellite_output.txt}

We make a few important changes. We previously fitted a model using the normalized bins, and normalized our model as well. Here, the true distribution must be put into our test as integer values, so we unnormalize our integrated function to make them match.

For each dataset, we calculate the degrees of freedom as: $k = N - M$ with $N$ the number of data points (so the number of bins, which is the same as in b and c), and $M$ the number of parameters. This number is 3, as a, b and c are the three independent parameters that are fitted. A does not count, as it is fully constrained by the other parameters.
